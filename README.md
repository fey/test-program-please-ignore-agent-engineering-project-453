# Агент разбора инцидентов

[![hexlet-check](https://github.com/fey/test-program-please-ignore-agent-engineering-project-453/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/fey/test-program-please-ignore-agent-engineering-project-453/actions)

Постройте агента, который получает реальные ошибки приложения, создаёт GitHub issue, сам исправляет код и открывает PR. Добавьте повторную проверку, эвалы и улучшите агента по результатам экспериментов.
